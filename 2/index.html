Part One

Convolutions from Scratch

Four loops, two loops, and a comparison against SciPy.

I implemented 2D convolution with NumPy only: flip the kernel, zero-pad the image ("same" or "full"), then slide over the padded image.

Four Loops

Visits every output pixel and every kernel entry explicitly, accumulating one product at a time.

Two Loops

Visits every output pixel, but replaces the inner two loops with one elementwise product and sum over the patch.

Padding + Convolution 
def pad_zero(image, kernel, mode="same"):
    kh, kw = kernel.shape
    ph, pw = (kh // 2, kw // 2) if mode == "same" else (kh - 1, kw - 1)
    return np.pad(image, ((ph, ph), (pw, pw)), mode='constant', constant_values=0)

def conv2d_4loops(image, kernel, mode="same"):
    kernel = kernel[::-1, ::-1]                       
    kh, kw = kernel.shape
    padded = pad_zero(image, kernel, mode)
    H_out, W_out = padded.shape[0] - kh + 1, padded.shape[1] - kw + 1
    out = np.zeros((H_out, W_out))
    for i in range(H_out):
        for j in range(W_out):
            acc = 0.0
            for u in range(kh):
                for v in range(kw):
                    acc += padded[i + u, j + v] * kernel[u, v]
            out[i, j] = acc
    return out

def conv2d_2loops(image, kernel, mode="same"):
    kernel = kernel[::-1, ::-1]
    kh, kw = kernel.shape
    padded = pad_zero(image, kernel, mode)
    H_out, W_out = padded.shape[0] - kh + 1, padded.shape[1] - kw + 1
    out = np.zeros((H_out, W_out))
    for i in range(H_out):
        for j in range(W_out):
            out[i, j] = np.sum(padded[i:i + kh, j:j + kw] * kernel)
    return out

Runtime & boundaries

The 4-loop version is slowest because every multiply-add runs in interpreted Python. The 2-loop version pushes the kernel arithmetic into vectorized NumPy (about 7× faster), and SciPy is faster still (about 200× vs. 4 loops) because its loops are compiled. All three zero-fill the boundary (boundary='fill', fillvalue=0 in SciPy), so pixels near the border mix in the implicit black frame and get darkened after blurring. Derivative of Gaussian filters

By associativity, Dx ∗ (G ∗ I) = (Dx ∗ G) ∗ I, so I convolved G with Dx and Dy once (mode='full', giving 9×11 and 11×9 filters) and applied them directly to the original image.

Part Two

Image Sharpening

Unsharp masking: add back the high frequencies.

A Gaussian G is a low-pass filter, so I − G∗I keeps only the high frequencies (edges, texture). Images look sharper with stronger high frequencies, so:

I_sharp = I + α(I − G∗I) = ((1 + α)·δ − α·G) ∗ I

where δ is the impulse (identity) filter. The right-hand form is the single unsharp mask filter: one convolution with kernel (1+α)δ − αG. I convolve each RGB channel separately (9×9 kernel, σ = 2) and clip to [0, 1].

Unsharp mask 
def unsharp_mask(img, ksize=9, sigma=2, alpha=1.0):
    blurred = convolve2d_color(img, gaussian_kernel(ksize, sigma))
    high_freq = img - blurred
    return np.clip(img + alpha * high_freq, 0, 1), blurred, high_freq

def unsharp_kernel(ksize, sigma, alpha):     
    G = gaussian_kernel(ksize, sigma)
    d = np.zeros_like(G); d[ksize // 2, ksize // 2] = 1
    return (1 + alpha) * d - alpha * G

Effect of α

α scales how much edge contrast is added. Small α gives a mild crispening; large α exaggerates edges, and bright/dark halos appear along strong contours, along with amplified noise and texture. Values are clipped to [0, 1], so very high α also saturates highlights and shadows.

The re-sharpened image looks crisper than the blurred one, but it does not match the original. What it adds is edge contrast, so fine texture stays smooth while edges get halos.

Hybrid Images

Low frequencies from one image, high frequencies from another.

Hybrid image 
def low_pass(img, sigma, ksize=None):
    if ksize is None: ksize = int(6 * sigma + 1) | 1     # odd
    k = gaussian_kernel(ksize, sigma)
    return convolve2d_color(img, k) if img.ndim == 3 else signal.convolve2d(img, k, mode='same')

def high_pass(img, sigma): return img - low_pass(img, sigma)

def hybrid_image(im_high_src, im_low_src, sigma_high, sigma_low):
    high, low = high_pass(im_high_src, sigma_high), low_pass(im_low_src, sigma_low)
    return np.clip(low + high, 0, 1), low, high

Part Two

Gaussian & Laplacian Stacks

Like pyramids, but never downsampled.

Each Gaussian stack level blurs the previous one with the same σ = 2 kernel (no subsampling, so every level keeps the original size). Laplacian level i is Gi − Gi+1 (a band-pass), and the last level is the final Gaussian, so summing all Laplacian levels reconstructs the image exactly.

Stacks 
def gaussian_stack(img, levels, sigma=2, ksize=None):
    if ksize is None: ksize = int(6 * sigma + 1) | 1
    kernel = gaussian_kernel(ksize, sigma)
    stack = [img]
    for _ in range(1, levels):
        prev = stack[-1]
        stack.append(convolve2d_color(prev, kernel) if img.ndim == 3 else
                     signal.convolve2d(prev, kernel, mode='same', boundary='fill', fillvalue=0))
    return stack

def laplacian_stack(g):
    return [g[i] - g[i + 1] for i in range(len(g) - 1)] + [g[-1]]

Part Two

Multiresolution Blending

Blend each frequency band with its own mask blur.

For inputs A, B and a mask M: build Laplacian stacks of A and B and a Gaussian stack of M, blend each level as Mi·LA,i + (1 − Mi)·LB,i, and sum the levels. Since the mask blur grows with level, low frequencies blend across a wide seam and high frequencies across a narrow one. I used 5 levels and σ = 10, in color.

Blend 
def blend(im1, im2, mask, levels=5, sigma=2):
    l1 = laplacian_stack(gaussian_stack(im1, levels, sigma))
    l2 = laplacian_stack(gaussian_stack(im2, levels, sigma))
    gm = gaussian_stack(mask, levels, sigma)
    out = []
    for i in range(levels):
        m = gm[i][:, :, None] if im1.ndim == 3 and gm[i].ndim == 2 else gm[i]
        out.append(m * l1[i] + (1 - m) * l2[i])
    return np.clip(np.sum(out, axis=0), 0, 1), out, gm, l1, l2

Reflection

Most Important Thing I Learned

Frequency is a useful way to think about images. Blurring, sharpening, edge detection, hybrid images and seamless blends are all the same idea (choose which frequency bands to keep, and treat each band at its own scale). Associativity of convolution turned two steps into one DoG filter, and blending per band is why the seam disappears. Also it is super fun to merge and blend random things together but also really hard to get it to look right! Lots of trail and error.
