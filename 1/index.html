Mission Brief

Introduction

The Prokudin-Gorskii collection contains historical photographs captured as three separate color exposures. The goal of this project is to reconstruct these grayscale exposures into a single color image.

The core challenge is alignment: the three color channels were captured separately, so their pixels do not initially line up.

For each photograph, I treated the blue channel as the reference and search for the displacement of the green and red channels that produces the best match.

01

Phase One

Single-Scale Alignment

Establishing a baseline using exhaustive search with normalized cross-correlation (NCC).

I first implemented alignment at a single resolution.

NCC

Measures normalized correlation between the two channels, reducing sensitivity to overall brightness differences.

NCC score calculation 


    def ncc_score(im1, im2):
        v1 = (im1 - im1.mean()).flatten()
        v2 = (im2 - im2.mean()).flatten()
        return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
Alignment Implementation 

def align(base, moving, window=15):
    best_score = 0
    best_offset = (0, 0)
    for dy in range(-window, window + 1):
        for dx in range(-window, window + 1):
            shifted = shift_im(moving, dx, dy)
            score = (ncc_score(crop_border(base), crop_border(shifted)))
            is_better = (score > best_score) 
            if best_score == 0 or is_better:
                best_score = score
                best_offset = (dx, dy)
    return best_offset

Phase Two

Multi-Scale Pyramid

Scaling the alignment process to the high-resolution TIFF images.

Exhaustively searching every possible offset becomes impractical as image resolution and displacement increase. For example, the other images are far larger than the previous few, thus processing them using the single alignment algorithm would take too long.

I therefore used a coarse-to-fine image pyramid. The alignment is first estimated at a lower resolution and then refined at progressively higher resolutions.

Coarse Search

Large displacements can be searched efficiently on a small image.

Fine Refinement

The estimated displacement is scaled and refined at each higher resolution.

Coarse-to-Fine Algorithm 

def pyramid_align(base, moving, window=5, min_size=64):
    if min(base.shape[:2]) <= min_size:
        return align(base, moving, window=15)  

    small_base = resize_half(base)
    small_moving = resize_half(moving)
    dx_coarse, dy_coarse = pyramid_align(small_base, small_moving, window=window, min_size=min_size)

    dx_guess, dy_guess = dx_coarse * 2, dy_coarse * 2

    pre_shifted = shift_im(moving, dx_guess, dy_guess)
    dx_refine, dy_refine = align(base, pre_shifted, window=window)

    return dx_guess + dx_refine, dy_guess + dy_refine

Refinement

Improving Alignment

Moving beyond raw pixel matching to address difficult alignment cases.

The baseline approach works well when the corresponding channels have similar intensity patterns, but some photographs violate this assumption, specifically Emir.

Difficult Case — Emir

Emir is difficult because the three exposures have substantially different brightness/intensity characteristics. His bright blue robe has different brightness values in the red and blue exposure, causing the great disparity in alignment we see above.

Improved Feature / Distance Metric

The original alignment algorithm uses NCC to compare the raw pixel intensities of the different color channels. However, this can be unreliable when the channels have different brightness or exposure. To improve this, I used a gradient-based approach that first computes the gradient magnitude of each channel using Sobel filters. This focuses the alignment on structural features such as edges and object boundaries, which are more consistent across the channels. NCC is then applied to these gradient images to find the best displacement. I also retained the image pyramid approach so that large displacements can first be found at lower resolutions and then refined at higher resolutions.

Improved Alignment 

def gradient_magnitude(im):

    gx = cv.Sobel(im, cv.CV_32F, 1, 0, ksize=3)
    gy = cv.Sobel(im, cv.CV_32F, 0, 1, ksize=3)

    magnitude = np.sqrt(gx ** 2 + gy ** 2)

    return magnitude

def gradient_align(base, moving, window=15):

    # Compute gradients once
    base_gradient = gradient_magnitude(base)
    moving_gradient = gradient_magnitude(moving)

    best_score = -np.inf
    best_offset = (0, 0)

    for dy in range(-window, window + 1):
        for dx in range(-window, window + 1):

            shifted = shift_im(
                moving_gradient,
                dx,
                dy
            )

            score = ncc_score(
                crop_border(base_gradient),
                crop_border(shifted)
            )

            if score > best_score:
                best_score = score
                best_offset = (dx, dy)

    return best_offset
